# **mini-Airbnb-data-manager**
This project is made to analyze,read,clean the data about airnab listing such as price,reviews,minimum night person stay and also for learning, how data of any industry got managed this is beginner friendly project which uses pandas and numpy (special liberies of python) also the tkinter ia also used for gu 

**with this project you can**:
Load Airbnb data from a file (like CSV or Excel).

Clean the data (remove missing values, fix wrong formats).

Do simple analysis (find average prices, count listings, check reviews).

Show results with charts and graphs.
